# One Beast — веб-прототип

Ранний прототип игры One Beast: один зверь, которого ты растишь, кормишь и воспитываешь. Графика на emoji, это проверка механик, а не финальный вид.

**Играть:** https://usakuzmin.github.io/one-beast-prototype/

**Все версии:** https://usakuzmin.github.io/one-beast-prototype/versions/

## Как играть

- Открой ссылку в браузере (лучше на компьютере), выбери зверя и играй.
- Прогресс сохраняется в браузере. Кнопка «Новый зверь» начинает заново.
- Если закрыть вкладку и вернуться позже, игра покажет, что было «пока тебя не было».

## Как прислать журнал

Если что-то странное, сломалось или просто хочется поделиться игрой:

1. Нажми ⚙ в верхней панели (или клавишу **D**), откроется панель «Отладка».
2. Нажми **⬇ Экспорт JSON**, скачается файл `one_beast_<имя>_<дата>.json`.
3. Пришли этот файл автору вместе с парой слов, что делал и что увидел.

## Для автора

Здесь лежит только собранная игра (`index.html`, один файл). Новая версия выкладывается заменой `index.html` и пушем в `main`; GitHub Pages обновляет сайт за минуту-две.

Каждая рабочая версия лежит в своей папке `versions/<версия>/index.html` и открывается по своей ссылке. Список версий — в `versions/index.html`. Новая версия добавляется новой папкой и строкой в списке, старые не меняются.
